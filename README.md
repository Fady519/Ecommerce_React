## ✨ Features

| Feature | Description |
|---|---|
| 🔐 **Authentication** | Register & Login with JWT token handling |
| 🛍️ **Products & Categories** | Browse products filtered by category |
| 🛒 **Shopping Cart** | Add, remove & update cart items in real-time |
| ❤️ **Wishlist** | Save favourite products for later |
| 📦 **Orders & Checkout** | Place and track orders end-to-end |
| ✅ **Form Validation** | Powered by **Formik + Yup** for clean UX |
| 🔔 **Toast Notifications** | Real-time feedback via **React Hot Toast** |
| 🎠 **Sliders & Carousels** | Smooth product sliders with **React Slick** |
| ⏳ **Loading States** | Beautiful spinners via **React Loader Spinner** |
| 🚀 **Fast & Optimized** | Built with **Vite** + **TanStack React Query** caching |

## 🔌 API

This app consumes the **Route Misr E-Commerce API**:

```
Base URL: https://ecommerce.routemisr.com/api/v1
```

| Endpoint | Description |
|---|---|
| `POST /auth/signup` | Register a new user |
| `POST /auth/signin` | Login & get JWT token |
| `GET /products` | Fetch all products |
| `GET /categories` | Fetch all categories |
| `GET /cart` | Get user cart |
| `POST /cart` | Add item to cart |
| `GET /wishlist` | Get user wishlist |
| `POST /orders` | Place an order |

## ⚙️ Getting Started

### Prerequisites

- Node.js `v18+`
- npm or yarn

### Installation

```bash
# 1. Clone the repo
git clone https://github.com/Fady519/Ecommerce_React.git
cd Ecommerce_React

# 2. Install dependencies
npm install

# 3. Start dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build & Deploy

```bash
# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
